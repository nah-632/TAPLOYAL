# ADR-002 — اعتماد مرجع البناء الجديد واللوقو المرفق

- **ID:** ADR-002
- **DATE:** 2026-11-09
- **STATUS:** **APPROVED** — بتوجيه المالك: «اريد منك اعتماد هذا البرومبت ليكون مرجعك في البناء فقط واعتماد اللوقو المرفق».
- **SUPERSEDES (للأمور البصرية والتصميمية والوظيفية):** `docs/spec-source.md` عند أي تعارض.
- **REMAINS BINDING:** توجيه CranL Native (ADR-001) — انظر §3.

| الأصل | الموقع في المستودع |

| مرجع البناء (1645 سطرًا · 15 قسمًا) | `docs/BUILD-PROMPT.md` — **النص كما وصل، بلا تعديل** |

## 2. تغييرات إلزامية نتجت عن الاعتماد

| Deep Navy `#0B1F3B` | Deep Navy **`#14243A`** |
| Teal `#00A996` | Electric Teal **`#16A6A1`** |
| Mint `#E6F7F2` | Soft Mint **`#DDF5F0`** |
| Cream `#FAFAF7` | Warm White **`#FAFBFC`** |

| — | Midnight Blue `#1D3557` (جديد) |

**دليل حذف الذهبي (لا تفضيل شخصي):** قياس بكسلات اللوقو المرفق ⇒ **كحلي 45.9%** (`#081E36`) · **تركوازي 11.7%** · ولا ذهبي إطلاقًا. والبرومبت الجديد لا يذكره. المصدران متطابقان.

**التنفيذ:** `app/globals.css` حُدِّث بالكامل، وكل استخدامات `gold`/`cream` في الواجهة أُزيلت (تحقق: `rg 'gold|cream' app/` ⇒ لا نتائج في JSX).

### ب. تسميات الخطط
الباقة الأعلى اسمها **`Professional`** (كانت `Pro`). ملاحظة مفتوحة: الجداول الحالية تستخدم `plan_code = 'free' | 'basic' | 'pro'` ⇒ يلزم migration إذا أُريدت المطابقة الحرفية.

### ج. إضافات على الستاك
`React Hook Form` + `Zod` مطلوبان في §7 ولم يكونا في الستاك السابق. **فجوة قائمة:** لا يوجد أي نموذج مُنفَّذ بعد، فالإضافة بلا كلفة ترحيل.

### د. عناصر تصميم جديدة
Sidebar بأسماء محدّدة (`Card Designer` بدل `Loyalty Program` مفردًا) · Header يشمل **اختيار الفرع** · لا Glassmorphism · منع التدرجات المبالغ فيها.

## 3. ⛔ تعارض يجب إبرازه (لم يُحسم صامتًا)

`docs/BUILD-PROMPT.md` **يذكر Supabase وVercel** — لكن بصيغة **خيارات** لا إلزام:
```
§7: "Supabase أو PostgreSQL مُدار" · "Supabase Auth أو مزود موثوق"
    "Supabase Storage أو خدمة Object Storage موثوقة" · "Vercel للواجهة…"
```
ويذكر أيضًا `Row Level Security عند استخدام Supabase` (§6) بوصفه **شرطيًا** («عند استخدام»).

**القرار:** توجيه المالك الصريح والمُسمّى («لا تستخدم أي خدمة Supabase… احذف جميع إعدادات Vercel») هو **رتبة أعلى وأكثر تحديدًا** من قائمة خيارات في مرجع عام. ⇒ **البنية تبقى CranL Native**، وقد تحقّق ما يطلبه البرومبت فعلًا:
- PostgreSQL مُدار ✅ (CranL, PG 16.15)
- مصادقة موثوقة يملكها التطبيق ✅ (Better Auth + Argon2id)
- Object Storage ⛔ **محجوب على الخطة** (`buckets: 0`) — لم يُدَّعَ كمنجز
- RLS ✅ PostgreSQL أصلي (لا Supabase RLS) + دور `NOBYPASSRLS` + اختبارات كاناري

**يحتاج تأكيدًا من المالك** إن كان يقصد إلزام Supabase/Vercel صراحةً — ساعتها نحتاج ترحيلًا كاملًا عكس ADR-001.
